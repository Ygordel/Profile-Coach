# 🚀 Portfólio Profissional — Ygor Silva

## 💻 Tecnologia • Redes • Segurança • IA • Telecomunicações • Educação • Direito Digital

Este projeto apresenta meu **portfólio profissional e acadêmico**, desenvolvido como uma página web responsiva para centralizar minha trajetória, experiências profissionais, produção científica, aprovações, projetos e principais áreas de atuação.

A proposta é unir **Tecnologia da Informação, infraestrutura, redes de computadores, telecomunicações, segurança da informação, Inteligência Artificial, educação e Direito Digital** em uma apresentação profissional moderna e organizada.

## 🤖 Projeto de Pesquisa

Um dos principais interesses apresentados no projeto é a aplicação de **Inteligência Artificial ao monitoramento inteligente de redes corporativas**.

A proposta de pesquisa envolve a utilização de técnicas de IA para:

- identificação de anomalias;
- análise de comportamento da rede;
- monitoramento de infraestrutura;
- apoio ao diagnóstico de incidentes;
- identificação de padrões;
- auxílio ao troubleshooting;
- melhoria da disponibilidade dos serviços;
- apoio à tomada de decisão.

O projeto busca aproximar **monitoramento de redes, análise de dados e Inteligência Artificial**, criando soluções capazes de auxiliar equipes de infraestrutura e operações de rede.
